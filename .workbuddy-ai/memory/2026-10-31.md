## 内置媒体查看器方案（docs/media-viewer-design.md）

- 需求：双击图片/视频/音频 → 新标签页播放，标签内右侧播放列表侧边栏列同目录媒体。
- 关键架构事实（调研结论，后续复用）：
  - 标签系统 = `MainWindowViewModel.Tabs`（`ObservableCollection<object>`）+ `MainWindow.axaml` 的 `ContentControl.DataTemplates` 按类型映射面板；`ITabView`（Services/TabContract.cs）负责调试镜像快照，未知类型回退 `TabKinds.Unknown`。
  - 双击入口在 `FileListPanel.axaml.cs:OnRowDoubleTapped` → `FileTabViewModel.OpenEntry`（本地文件当前一律 `Process.Start` 系统程序）。
  - **项目没有任何 WebView 依赖**，终端是 TextBox 行模式（README 的 xterm.js 仍未接入）。
  - `WebServiceHost` 是手写 HTTP 服务，`/api/file` 不支持 Range。
- 技术选型结论：图片 = Avalonia Bitmap + SkiaSharp 逐帧；音视频 = LibVLCSharp（libvlc）统一后端；元数据 = MetadataExtractor(Apache-2.0) + TagLib#(LGPL)；避开 ImageSharp（商用收费）、Flyleaf/mpv/ImageGlass（GPL，仅借鉴交互）。
- 核心风险：NativeControlHost 空域问题（原生窗口盖住 Avalonia 弹出层）→ 控制条放画面下方、全屏用独立 Window、弹出层用 Popup/独立窗口。
- 里程碑：M0 探针（LibVLCSharp.Avalonia 与 Avalonia 12.1.4 兼容性）→ M1 图片 → M2 音频 → M3 视频 → M4 增强（缩略图、Range 镜像、远程媒体）。
- 状态：方案待用户评审，4 个待拍板项（默认打开方式、重复打开合并、体积取舍、播放列表范围）。

## 内置媒体查看器 实施（已完成 M1–M3，2026-10-31 下午）

用户回复「执行推荐」→ 按推荐值全部落地：默认内置打开、同文件复用标签、接受体积、播放列表默认同类。

**环境**：本机原先没有 .NET SDK，用 dotnet-install.ps1 用户级装了 10.0.403 到 `~/.dotnet`（`$USERPROFILE/.dotnet/dotnet.exe`，未加入 PATH）。

**技术栈**：LibVLCSharp 3.10.2 + VideoLAN.LibVLC.Windows 3.0.24（仅 Windows 条件引用）；未用 LibVLCSharp.Avalonia，自建 `MediaSurfaceHost`（NativeControlHost + Win32 `CreateWindowExW("static")`）。

**三个必记的坑**：
1. `NativeControlHost` 挂载即创建原生窗口，与 IsVisible 无关 → 图片标签也会抛 `Unable to create child window`。必须改为按需 new（XAML 只留空 Panel）。
2. 缺 `app.manifest` 的 `supportedOS` 声明时，NativeControlHost 必抛同一异常 → 已加 manifest + `<ApplicationManifest>`。
3. `VideoLAN.LibVLC.Windows` 默认拷三套架构 = 303MB → csproj 加 `TrimLibVlcArchitectures` target 只留目标架构 = 108MB。

**实现期修的两个逻辑 bug**：
- 路径正/反斜杠不一致导致播放列表当前项不高亮 → `MediaTabViewModel.NormalizePath`（Path.GetFullPath）。
- ListBox.SelectedItem 程序同步触发 SelectionChanged → 打开后自动切走媒体；`OnPlaylistSelectionChanged` 加「路径相同则返回」守卫。

**验证手段（无 GUI 自动化时很有效）**：调试镜像 `http://127.0.0.1:15919/api/state` 能读回全部标签快照（含 FillMedia 的播放列表行），配合临时环境变量探针（TTX_MEDIA_PROBE）自动开标签，即可在无截图能力时验证 UI 状态；探针验证完已删除。
截图在本环境不可用（Add-Type / Reflection.Assembly.Load 都被安全策略拦截）。

**结果**：图片/音频(3s wav)/视频(10s mp4) 三类真机验证通过；`dotnet test` 190 通过；文档已回填 §11 落地结果。
**未做（M4）**：缩略图、字幕/音轨菜单 UI、TagLib/MetadataExtractor 元数据、GIF 逐帧、镜像页 Range 播放、远程媒体。
