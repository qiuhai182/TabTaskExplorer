# GAP：现有实现与现代化方案的差距清单

状态：2026-11-03
依据：本仓库代码盘点（只读）+ `docs/modern-design/` 41 个模块设计稿
口径：严重度 P0=阻断核心体验/安全；P1=明显落后于同类产品；P2=完善项。差距类型：缺失、半成品、体验、安全、跨平台、性能。

## 3. 已有能力（不应回退）

- 标签拖动排序、拖出成新窗口、会话恢复（文件路径）。
- 文件：批量改名、压缩/解压、比对、信息窗格、后台分页读取、虚拟化。
- 磁盘：驱动器总览、懒加载树、大小回填、排序、扫描进度。
- IDE：预览编辑器、快速打开、查找替换、工作区搜索、编码探测、远程保存回传。
- 截图：多屏物理坐标拼接、窗口/子视图预选、Tab/滚轮层级、取消全流程、延迟、上次区域、贴图截图、取色。
- 录屏：FFmpeg 定位、H.264/CRF、帧率、麦克风、计时、停止收尾。
- 标注/贴图：11 种工具、撤销/重做、透明度/缩放/旋转、OCR/条码。
- OCR：Windows 本地识别（离线）、Tesseract 回退、行框结果。
- 远程：SSH 密码 + keyboard-interactive、私钥、保活；SFTP 文件系统/chmod；FTP 文件系统；传输暂停/续传/递归/重试。
- 连接管理：增删改查、DPAPI（Windows）、导入导出、Xshell 一键导入、TCP 测试。
- 终端：行模式、输出缓冲、ANSI 清理、会话日志、快捷命令、重连。
- 搜索：Everything IPC + 遍历回退、`path:/case:/ext:` 语法、排序。
- 书签/导航：固定路径、书签栏、左侧导航、此电脑、最近访问（内存）。
- 会话：多窗口、单实例、拖出/拖入、系统唤起去重。
- 剪贴板：文件列表 + Windows/GNOME/KDE 剪切标记、文本写入、内部回退。
- 系统集成：默认文件管理器（HKCU Directory）、开机自启三平台、AUMID、单实例。
- 进程：列表/树/详情/结束/优先级/亲和性/走势图/前台暂停。
- 任务看板：三列、新建/移动/删除、JSON 持久化、Web 镜像。
- 媒体：图片缩放/平移/旋转、视频/音频播放、播放列表、字幕、VLC。
- 比对：目录递归、文本 diff、差异导航、交换、过滤。
- 归档：多格式读取、创建、修改、虚拟目录、进度/取消、路径安全。
- 批量改名：查找替换/前后缀/序号/扩展名/预览。
- 取色/条码：全屏取色、放大镜、ZXing 解码。
- 右键：原生 IContextMenu + 第三方扩展 + 降级菜单 + 管理页。
- 拖放：来源区分（移动/只读拷贝）、效果协商、非法落点拒绝、窗口级落点。
