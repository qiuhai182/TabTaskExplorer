# 设置中心现代化设计

状态：设计稿（2026-11-03）
适用：`SettingsWindow`、`AppSettingsStore`、`AppSettings`
调研：联网检索（2026-11-03）+ 代码盘点

## 1. 现状

| 能力 | 代码位置 | 成熟度 | 说明 |
| --- | --- | --- | --- |
| 11 个分页 | `SettingsWindow.axaml:10-20` | 可用 | 基本设置、快捷操作、文件/文件夹、编辑器、打开方式、媒体、网页端、右键菜单、启动项管理、截图与录屏、关于 |
| 设置持久化 | `AppSettingsStore.Save/Load`（:223+）、`AppSettings`（:13-218） | 可用 | JSON 配置文件 |
| 设置即改即存 | `MainWindowViewModel.SaveSettingsAndApply`（:1619） | 可用 | 确定后统一保存并应用 |
| 快捷键中心 | `SettingsWindow` 第 1 分页 | 可用 | 多绑定、作用域、恢复默认 |
| 网页端端口/权限方案 | `SettingsWindow` 第 6 分页 | 可用 | 多端口、来源/路径白名单、读写/增删权限、密码 |
| 右键菜单管理 | `SettingsWindow` 第 7 分页 | 可用 | 注册表项筛选、启停、刷新 |
| 启动项入口 | `SettingsWindow` 第 8 分页 | 可用 | 跳转到启动项管理标签页（统一一份界面） |
| 截图/录屏设置 | `SettingsWindow` 第 9 分页 | 可用 | 目录、FFmpeg、延迟、帧率、画质、麦克风、OCR |
| 设置搜索 | 无 | 缺口 | 11 页只能逐页找 |
| 导入/导出/重置全部 | 无 | 缺口 | 换机迁移靠手抄 |
| 分页级重置 | 无 | 缺口 | 只能“恢复默认快捷键” |
| 校验与错误汇总 | 半成品 | 半成品 | 端口/路径等校验分散，缺少统一错误提示 |
| 脏状态提示 | 无 | 缺口 | “确定/取消”模型，无“未保存”标记 |

主要问题：

1. **无搜索**：用户不知道“FFmpeg 路径”在哪个分页；设置项越多越严重。
2. **无导入/导出/重置全部**：配置迁移、故障恢复困难。
3. **校验弱**：端口范围、路径存在性、FFmpeg/Tesseract 可执行性、快捷键冲突分散在各页，缺少统一“保存前校验”清单。
4. **分页过重**：网页端分页同时管理端口与权限方案，表格 + 多表单，认知负担高；右键菜单分页直接嵌入注册表项列表。
5. **无设置项元数据**：每一项没有“默认值/作用域/是否需要重启/风险说明”，无法生成搜索索引或帮助。
6. **无键盘/读屏优化**：分页 ListBox 与表单缺少明确的 Tab 顺序、AccessKey、标签关联。
7. **“确定”即全量保存**：没有“应用”与“取消”的差异预览；某些设置（网页端端口）会立即重启服务，用户可能未预期。
8. **部分设置未暴露**：录屏时长上限、贴图虚拟桌面、日志级别、更新通道等。

## 2. 业界对照

| 产品/能力 | 做法 | 对本项目启示 |
| --- | --- | --- |
| VS Code Settings | 搜索设置项、JSON 视图、按类别分组、重置单项（[文档](https://code.visualstudio.com/docs/getstarted/settings)） | 搜索 + 单项重置是基准 |
| Windows 11 设置 | 左侧分类 + 搜索 + 每项说明 + 推荐值 | 分类与搜索 |
| Directory Opus Preferences | 树形分类 + 搜索 + 导入导出配置 | 复杂配置的树形组织 |

| Snipaste 设置 | 简洁分类 + 快捷键/贴图/输出 | 轻量工具不应设置过载 |

## 3. 推荐方案

### 必做（P0）

1. **设置项注册表 + 搜索**
   - 每项设置定义元数据：Key、显示名、分页、控件类型、默认值、说明、是否需重启、风险级别、关键词。
   - 顶部搜索框按显示名/说明/关键词过滤，结果直接跳转并高亮。
   - 接入点：新增 `Services/SettingsCatalog.cs`；`SettingsWindow.axaml` 顶部搜索框；各分页控件绑定 Key。
   - 注意：不要求一次性重写 11 页，可先为高频项（截图、网页端、编辑器、快捷键）建元数据。

2. **导入 / 导出 / 重置**
   - 导出当前配置 JSON（可选“仅非默认项”）；导入时校验 schema 并合并；支持“重置全部/重置当前分页/重置单项”。
   - 接入点：`AppSettingsStore`、`SettingsWindow` 底部按钮；`AppSettings` 增加 `SchemaVersion`。

3. **保存前校验**
   - 统一校验器：端口 1024–65535、路径存在/可写、FFmpeg/Tesseract 可执行、快捷键冲突、网页端至少一个端口、代理/证书（如有）。
   - 校验失败在对应分页标红，并在底部汇总“3 项需要修正”。
   - 接入点：新增 `Services/SettingsValidator.cs`；`SettingsWindow.OnOkClick`。

4. **分页瘦身**
   - 网页端：端口列表与权限方案拆成两个子页/两个卡片，方案编辑用抽屉。
   - 右键菜单：列表 + 右侧详情，避免整页表格。
   - 启动项：保持跳转到独立标签页（已有），设置页只保留入口。
   - 接入点：`SettingsWindow.axaml` 结构调整。

5. **可访问性与键盘**
   - 每个输入控件有关联 Label；Tab 顺序按视觉顺序；Ctrl+S 保存；Esc 取消；搜索框 Ctrl+F 聚焦。
   - 接入点：`SettingsWindow.axaml`、`App.axaml` 样式。

### 可选（P1/P2）

- 配置预设/配置文件（“办公”“截图”“开发”）。
- 设置同步（用户选择目录/WebDAV），默认关闭。
- 策略锁定（企业环境只读项），P2。
- 设置变更历史（最近 10 次，可回滚）。
- “需要重启”项在保存后提示重启，而不是静默无效。

### 不建议

- 把所有设置塞进一个长页面：分页 + 搜索更清晰。
- 把配置写入注册表：JSON 已足够，便于迁移与备份。
- 无确认地重启网页端服务：应在保存时提示影响。

## 4. 交互与视觉

- 左侧分页 200px，右侧内容区最大宽 720，避免表单过宽。
- 顶部搜索框 36px，结果下拉显示“分页 > 设置项”。
- 每项：标题 + 说明（弱化）+ 控件；危险项加警告图标。
- 底部：恢复默认（当前页）、导入、导出、取消、确定；校验失败时“确定”禁用并显示原因。
- 网页端分页：端口卡片（端口/绑定范围/方案/启用）+ “新增端口”；方案卡片（来源/路径/权限/密码）。
- 视觉：沿用现有 Fluent 风格；分组用 1px 分隔线与 16px 间距。

## 7. 验收标准

1. 搜索“FFmpeg”能在 1 秒内定位到截图页对应控件并高亮。
2. 导出配置后清空应用数据，再导入可恢复全部设置（密码字段按策略处理）。
3. “重置当前分页”只影响该页；重置全部需二次确认。
4. 端口非法、路径不存在、FFmpeg 不可执行时，保存被阻止并定位到具体控件。
5. 设置页全部控件可用 Tab 到达，标签关联正确；Ctrl+S 保存生效。
6. 网页端端口变更保存前提示“将重启服务”，确认后状态栏反映新地址。
7. 设置项说明中明确标注“需要重启”的项，保存后给出重启提示。
